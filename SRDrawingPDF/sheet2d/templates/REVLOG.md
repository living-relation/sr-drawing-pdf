# Rev log

Same table as the drawing rev log (top right of sheet 1). One row per release, never per
edit. Clerical revs (C.01, C.02 ...) are not listed. Rev A is always "Initial". When the
table on the drawing is long, the sheet shows the newest rows; this file keeps them all.

| Rev | Description | By (initials of the requester, never an agent) | Date (dd/mm/yy) |
|---|---|---|---|
| A | Initial | <initials> | <dd/mm/yy> |
